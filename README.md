# Tipping the Tax — interactive companion
Public deployment of the interactive companion to the working paper
"Tipping the Tax: How Government Surcharges Become Gratuities"
(Sotomayor & Uceda-Sosa, Columbia University, 2026).

**Canonical source lives in the private research repo** at `site/index.html`
(tylersotomayor/tipping-the-tax). To redeploy: copy that file here and push.
All data embedded in the page is computed from the paper's committed
estimation cells and replication logs.
